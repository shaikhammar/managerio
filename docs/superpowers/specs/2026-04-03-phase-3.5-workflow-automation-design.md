# Phase 3.5 — Workflow Automation

**Date:** 2026-04-03
**Status:** Approved

---

## Overview

Four automation features that reduce manual overhead for translation project managers: translator suggestions in the project edit form, automatic PO generation when a project goes In Progress, daily invoice reminder emails for overdue invoices, and deadline alert emails to assigned translators two days before a project is due.

---

## Decisions Made

| Feature | Decision |
|---|---|
| Auto-assign translator | Suggestion UI — ranked suggestions via a per-target "Suggest" button; PM still confirms |
| Auto-PO trigger | Event-driven — `ProjectMovedToInProgress` → listener → existing `generatePurchaseOrders()` |
| Invoice reminder frequency | Tiered — first reminder at ≥1 day overdue, re-send every 7 days; tracked via `last_reminder_sent_at` |
| Deadline alert window | 2 days before deadline; one-time per project via `deadline_alert_sent_at` |

---

## Architecture

### Feature 1 — Translator Suggestions

**Service:** `TranslatorSuggestionService::suggest(Business $business, int $languagePairId, int $serviceTypeId): Collection`

Scoring algorithm:
1. Filter `TranslatorProfile` records for the business that have the matching `languagePairId` in their `languagePairs` pivot and `serviceTypeId` in their `serviceTypes` pivot.
2. Score each: `availability_score` (Available=2, Busy=1, OnLeave=0) + `quality_rating` (0–5).
3. Order by total score descending. Return top 5 with `contact_id`, `contact.name`, `availability`, `quality_rating`.

**Controller action:** `ProjectController::suggestTranslators(Request $request, Business $business, Project $project)`
- Validates `language_pair_id` and `service_type_id` query params.
- Returns JSON array of suggestions.

**Route:**
```
GET /{business}/translation/projects/{project}/suggest-translators
```
Inside the existing `business.set` + `business.access` middleware group.

**Frontend:** In `resources/js/pages/translation/projects/edit.tsx`, each target row gets a "Suggest" button next to the translator assignment dropdown. On click, it calls the endpoint and populates an ordered dropdown list. Selecting a suggestion sets the `contact_id` on that assignment. The button is disabled until `language_pair_id` is set.

### Feature 2 — Automatic PO Generation

**Event:** `App\Events\ProjectMovedToInProgress` — carries the `Project` instance.

**Trigger:** `ProjectService::updateStatus()` fires this event immediately after `$project->update(['status' => $newStatus])` when `$newStatus === ProjectStatus::IN_PROGRESS`.

**Listener:** `App\Listeners\AutoGeneratePurchaseOrdersListener`
- Calls `ProjectService::generatePurchaseOrders($event->project)`.
- The service already skips assignments with an existing `purchase_order_id`.
- If no assignments exist, logs a debug message and returns silently — no exception.

**Registration:** `AppServiceProvider::boot()` — follows existing `InvoicePosted` pattern.

---

### Feature 3 — Invoice Reminders

**Migration:** `add_last_reminder_sent_at_to_invoices_table`
- Adds `last_reminder_sent_at` (nullable timestamp) to `invoices`.

**Invoice model:** Add `last_reminder_sent_at` to `$fillable`; cast to `datetime`.

**Command:** `App\Console\Commands\SendInvoiceReminders` (`invoice-reminders:send`)
- Queries SENT invoices scoped to each business where `due_date < today` AND (`last_reminder_sent_at IS NULL` OR `last_reminder_sent_at <= 7 days ago`).
- Skips if the contact has no email or if business SMTP is not configured.
- Sends `InvoiceReminderMail` queued; updates `last_reminder_sent_at = now()`.
- Outputs count of reminders sent.

**Schedule:** `routes/console.php` — `Schedule::command('invoice-reminders:send')->dailyAt('08:00')`.

**Mailable:** `App\Mail\InvoiceReminderMail` — implements `ShouldQueue`.
- Addressed to `$invoice->contact->email`.
- Includes: invoice number, amount due, due date, days overdue.
- Template: `resources/views/emails/invoice-reminder.blade.php`.

---

### Feature 4 — Project Deadline Alerts

**Migration:** `add_deadline_alert_sent_at_to_projects_table`
- Adds `deadline_alert_sent_at` (nullable date) to `projects`.

**Project model:** Add `deadline_alert_sent_at` to `$fillable`; cast to `date`.

**Command:** `App\Console\Commands\SendProjectDeadlineAlerts` (`project-alerts:send-deadline`)
- Queries IN_PROGRESS and REVIEW projects where `deadline = today + 2 days` AND `deadline_alert_sent_at IS NULL`.
- For each project, loads `assignments.contact` and sends `ProjectDeadlineAlertMail` to each assigned translator contact's email.
- Skips translators with no email.
- Updates `deadline_alert_sent_at = today`.
- Outputs count of alerts sent.

**Schedule:** `routes/console.php` — `Schedule::command('project-alerts:send-deadline')->dailyAt('07:00')`.

**Mailable:** `App\Mail\ProjectDeadlineAlertMail` — implements `ShouldQueue`.
- Addressed to the assigned translator's contact email.
- Includes: project name, reference, deadline, language pair, service type.
- Template: `resources/views/emails/project-deadline-alert.blade.php`.

## Testing

### Feature Tests (`tests/Feature/Workflow/`)

**`InvoiceReminderTest`**
- Overdue SENT invoice with no prior reminder → reminder sent, `last_reminder_sent_at` updated.
- Overdue invoice with `last_reminder_sent_at` within 7 days → skipped.
- Overdue invoice with `last_reminder_sent_at` >7 days ago → re-sent.
- Invoice with no contact email → skipped.
- Non-SENT invoice (DRAFT, PAID, VOID) → skipped.

**`ProjectDeadlineAlertTest`**
- Project with deadline exactly 2 days out, IN_PROGRESS, no prior alert → alert sent to each assigned translator, `deadline_alert_sent_at` set.
- Project with `deadline_alert_sent_at` already set → skipped.
- Project with deadline 3+ days out → skipped.
- CLOSED/COMPLETED project → skipped (not IN_PROGRESS or REVIEW).

**`AutoPurchaseOrderTest`**
- Project with assigned translators moved to IN_PROGRESS → POs auto-created via event.
- Project with no assignments moved to IN_PROGRESS → no error, no POs.
- Project moved to IN_PROGRESS where POs already exist → not duplicated.

### Unit Tests (`tests/Unit/Services/`)

**`TranslatorSuggestionServiceTest`**
- Returns translators matching language pair + service type, sorted by score.
- Excludes translators not matching the language pair.
- OnLeave translators score below Available/Busy.
- Returns at most 5 results.
- Returns empty collection when no matches.
